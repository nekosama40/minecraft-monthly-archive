# ねこさま Server — Minecraft Monthly

1か月限定で遊んだMinecraftサーバーの活動記録です。

プレイヤーごとの遊び方、サーバー全体の集計、ランキング、建造物ギャラリーを
静的なアーカイブとして公開しています。

- ランキングと個人分析は10時間以上プレイした人が対象です
- ベストパートナーは近くで行動した記録から同行度で表示します
- 位置・交流指標は約15分間隔の記録から推定しています
- 戦闘時間率は本人の討伐・死亡記録から、拠点・トラップ・異常増加を除いて推定します
- Mob討伐数はトラップ地域と短時間の異常増加を除外した推定値です
- 個人の最終座標・UUIDは公開していません
- リアルタイム更新を行うサイトではありません
